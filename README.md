# Ресторанный Telegram-бот "Terassa" (Нячанг)

Полнофункциональный бот для автоматизации приема заказов ресторана, разработанный на **Python (aiogram 3.x)** с использованием **SQLite**.

## 🛠 Технологии
- **Язык**: Python 3.10+
- **Фреймворк**: aiogram 3
- **База данных**: SQLite (через `aiosqlite`)
- **Деплой**: Поддерживает размещение на GitHub и Render.

## 📂 Структура проекта
- `main.py` — Главный файл запуска, логика хендеров, состояний (FSM) и интерфейса.
- `database.py` — Управление подключением и таблицами базы данных SQLite.
- `menu_data.py` — Каталог блюд, напитков и популярных позиций ресторана.
- `requirements.txt` — Список зависимостей для сборки на сервере.
- `.env` — Конфигурационный файл с секретными токенами.
